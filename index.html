Core Features

Universal Ingestion

Extracts high-quality audio streams and keyframe slides from YouTube URLs, social media links, or local video/audio files directly.

Multimodal AI Synthesis

Uses Google Gemini 1.5 Flash (via OpenRouter) to combine transcriptions and keyframes into clean, structured Markdown learning roadmaps.

Direct Notion Integration

Parses synthesized Markdown output dynamically and pushes formatted tables, code fences, and logs straight to your Notion Database.

⚙️ Developer Guide & Local Setup (for local execution)
1. Clone & Set Up Directory

# Clone the repository and install dependencies

git clone <your-repo-url>

cd "demo p"

pip install -r requirements.txt

2. Setup Environment Variables (.env)

# Create a .env file and add your credentials

GEMINI_API_KEY=your_gemini_key

NOTION_TOKEN=your_notion_integration_token

NOTION_DATABASE_ID=your_database_id

OPENROUTER_API_KEY=your_openrouter_api_key

3. Start the Pipeline Applications

# Run the desktop client with interactive UI

Launch_KNIGHTHOOD_Engine.bat

# Or run the mock pipeline looping listener

python app.py --loop --interval 30
